THE WORLD TODAY — a front page summing up Monday, 23 November 2026 in one image. Lead: the COP31 climate summit collapses in Antalya. 35 stories in total (3 big + 32 short), every story tagged "23 NOV" with its source, spanning 7+ regions, under a masthead dated "MONDAY, 23 NOVEMBER 2026" and a black DATE CHECK bar. Drawn entirely in code (HTML/CSS + inline SVG) and rendered with headless Chrome to a single deterministic 1024×1024 PNG.

## Run it

Requires Node 22 and a Chrome binary (the program tries the workspace chrome-for-testing build first, then standard paths).

```sh
node main.ts
```

It writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default). Two runs produce a byte-identical image.
